# ft_transcendence

![Transcendence Miniature](ft_transcendence.png)

## 🎮 Description

ft_transcendence est une application web de jeu de Pong en temps réel avec fonctionnalités sociales. Ce projet constitue le point culminant du parcours web à l'école 42.

## ⚙️ Fonctionnalités

- Jeu de Pong multijoueur en temps réel et Remote
- Live Chat avec canaux publics/privés
- Profils utilisateurs personnalisables
- Système d'amis et matchmaking
- Classement des joueurs et statistiques

## 🛠️ Technologies utilisées

- Frontend: Javascript, Bootstrap
- Backend: Django
- Base de données: PostgreSQL
- Temps réel: Socket.io/WebSockets
- Containerisation: Docker
- API: Oauth42 2.0
- Monitoring: Grafana, Prometheus
- Assets 3D: Blender, Three.JS

## 🚀 Installation

```bash
# Cloner le dépôt
git clone https://github.com/votre-username/ft_transcendence.git

# Se déplacer dans le dossier
cd ft_transcendence

# Lancer avec Makefile
make
```

## 💡 Configuration

1. Créer un fichier `.env` basé sur `.env.example`
2. Configurer les clés API OAuth (42, Google, GitHub)
3. Configurer la base de données PostgreSQL

## 🔐 Sécurité

- Stockage sécurisé des mots de passe
- Protection contre les attaques XSS et CSRF
- Validation des données côté serveur
- Gestion sécurisée des sessions

## 📱 Compatibilité

- Application single-page responsive
- Compatible desktop et mobile
- Supporte les navigateurs modernes
